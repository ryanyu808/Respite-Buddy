# OpenStreetMap snapshot attribution

The geographic database files in `snapshot/` contain data © OpenStreetMap contributors, available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Source and contributor information: https://www.openstreetmap.org/copyright

The GraphML walking graph, destination points, geographic features and potential rest stops are derived from OpenStreetMap through OSMnx and Overpass. The geographic database and derived database are offered under ODbL 1.0. Sensory proxy fields are derived heuristic attributes, not observed environmental measurements. Metadata records the retrieval date and geographic boundary. Basemap tiles are provided by OpenStreetMap with attribution in the application.

These data terms do not assert a license for unrelated application code. Retain attribution and comply with ODbL obligations when redistributing the geographic data.
